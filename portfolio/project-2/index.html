Stock Trend & Sentiment Analysis

Project aims to create a web-based UI to analyse trending stocks and sentiment with regards to specific stocks.

Project Details

User can select from list of tickers and based on that 2 separate apps will select latest trends for stock based on Google Trends API and Sentiment Scores from several APIs. After this various graphs will showcase correlation and patterns for stock sentiments and trends.

In addition, data from Reddit was also analyzed to see relationships between price changes, returns and public sentiment towards specific stocks like GameStop.
